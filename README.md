# Dengue clinical study

Analysis code for a hospital cohort study of serologically confirmed dengue.

| Folder | Contents |
|---|---|
| [`clinical-screening-and-analysis/`](clinical-screening-and-analysis/) | Clinical and laboratory predictors of length of stay, ICU admission / transfusion and WHO-2009 class; the Bleeding–USG–Fever severity score; comparison with published scores; clustering; figures. See its README. |
| [`serotyping-analysis/`](serotyping-analysis/) | Reserved for the serotyping analysis (not yet added). |

Patient-level data are not included in this repository.
